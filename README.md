# 치팅 파인더

필기시험 부정행위 사례 도감과, 3×3 좌석에서 수상한 응시자를 찾아내는 60초 감독관 미니게임입니다. 한국뿐 아니라 해외 사례도 담았고, 결과는 링크 하나로 공유할 수 있습니다.

## 왜 만들었나

최근 시험 부정행위 보도가 늘면서 "어떻게 알아챘는가"가 궁금해졌습니다. 이 프로젝트는 수법을 알려 주는 대신 **보도·감독 지침·커뮤니티 정리, 그리고 업계 설명(독립 검증 아님, 귀 속 이어폰·뼈 전도·스마트워치 3종)에 있는 단서만** 보여 주고, 단일 행동만으로 사람을 단정할 수 없다는 점을 결과 화면에서 설명합니다. 근거 종류는 화면에 라벨로 표시합니다. 평범한 응시자를 반드시 함께 넣어, 의심만으로 사람을 모는 게임이 되지 않게 했습니다.

## 페이지

| 경로 | 내용 |
| --- | --- |
| `/` | 소개, 도감 보기, 게임 시작 |
| `/dex` | 사건·수법 도감 (필터, 출처, 근거 라벨) |
| `/play` | 60초 감독관 게임 |
| `/r?c=&m=&f=&t=` | 결과 공유 랜딩 (OG 태그, 친구 결과) |

## 로컬 실행

```bash
npm install
npm run dev        # wrangler dev, http://localhost:8787
npm test           # vitest
npm run typecheck
npm run e2e        # Playwright (시스템 Chrome 사용)
```

`npm run e2e`는 번들 브라우저를 설치하지 않고 macOS 시스템 Chrome을 씁니다.

## 데이터와 출처

- `public/data/cases.json`: 사건·수법 도감. 모든 항목은 출처 URL을 갖고, 사건에는 확인 수준(확인됨 / 수사 중·일부 추정 / 거론됨 / 미검증 소문)이 붙습니다.
- `public/data/innocents.json`: 평범한 응시자 15명과 "왜 정상인지" 설명.
- `docs/research/cheating-methods.md`: 조사 원문과 출처 목록.
- `docs/superpowers/specs/2026-11-17-catchcheating-design.md`: 설계 문서.

실명·별명·계정명은 싣지 않으며, 장비 모델·설정·회피법 같은 따라 하기 정보도 싣지 않습니다.

## 면책

뉴스 보도 기준 개요이며 따라 하기 안내가 아닙니다. 수사 중인 사건은 바뀔 수 있습니다.

## 상태

그림은 현재 임시 에셋입니다. 실제 에셋으로 교체하기 전에는 공개 배포하지 않습니다. 교체 절차는 `CLAUDE.md`에 있습니다.
