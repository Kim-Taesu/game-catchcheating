### A-2. 세무사·리트 사건 (2026-11, 진행 중) — 확인/추정 구분

세무사 시험 수석 합격자 사건은 수법이 계속 바뀌어 보도되고 있다. 화면에는 사건명만 쓰고 개인 이름·별명은 쓰지 않는다.

| 항목 | 상태 | 근거 |
| --- | --- | --- |
| 초소형 카메라로 문제 촬영 → 생성형 AI → 스마트폰으로 답 확인, 1차(객관식)·2차(논술) 모두 | **본인 자수서** (2026-11-15) | 한국일보·MBC·나무위키 |
| AI 안경·초소형 이어폰은 쓰지 않았다 | 본인 진술 (당초 의혹은 안경이었음) | 한국일보 |
| 직접 개조한 **계산기**를 활용 | **본인 자수서 + 경찰 판단** (11-17). 개조 방식·계산기의 실제 역할은 수사 중. 경찰은 "계산기로 답을 받아본 것은 아니"라는 취지로도 전함 | 한국일보·MBC |
| 본인 진술(스마트폰으로 확인)과 경찰 판단(개조 계산기)이 서로 다르고 정리되지 않음 | 수사 중 | 나무위키 |
| 계산기에 통신 기능(중계기)을 이식 | **추정**. 수험생 사이 관측일 뿐 확인된 사실 아님 | 한국경제 |
| 단추·안경에 카메라 은닉 | **추정**. 가정으로만 제시됨 (튀르키예 2024는 단추형 카메라 실제 사례) | 나무위키 |
| 몸에 선을 감는다 | **근거 못 찾음**. 어느 기사에서도 확인 못 함 | — |
| 초소형 액정으로 AI 답 확인 | 일부 매체 전언, 미확인 | 조세금융신문 제목 |
| 단독 범행 주장 | 본인 주장, 경찰 확인 중 | 한국일보 |

**왜 계산기였나 (보도)**: 세무사·회계사 시험은 계산기가 사실상 필수라 일반 계산기('쌀집 계산기')는 반입 허용. 겉모습으로는 내부 개조 여부를 알 수 없고, 폰·스마트워치·스마트안경 대응에서 걸러지지 않았다 (한국경제·와이드경제).
러시아 SNS 영상: 계산기 뒷면 카메라로 찍으면 5초 안에 정답 표시 (기사서술, 개별 검증 불가).

**감독 구멍 (보도)**: 폰 일괄 수거 없이 "전원 끄고 가방에" 안내만, 교실 CCTV 없음, 감독위원 4명 "특이사항 없음". 정부는 안경류 전수조사, 'AI 인스펙터' 확대, 전파탐지·차단 장비를 거론.

**LEET 2027학년도 (2026-07 시행) 안경 바꿔치기** — 확정 사례, 수험생은 익명
- 감독관 전수 검사 때는 **일반 안경**, 1교시 언어이해와 2교시 추리논증 **사이에 AI 스마트안경으로 교체**해 2교시 응시
- 시험 도중 감독관이 이상행동을 재확인하다 적발. 0점 처리, 4년 응시제한, 형사 고발
- 최근 5년 AI 글라스 부정행위 교육부 집계에 이 1건 (YTN, 김희정 의원실 자료)
- 단서: 한 번 검사했다고 끝이 아니라 **쉬는 시간 뒤 재점검**이 필요

**'리트냥이'(LEET 만점자) 건은 사례로 쓰지 않는다**: 온라인 의혹 단계. 공식 확인된 부정행위 없음. 근거로 거론된 것은 답 고친 흔적 등이고, 높은 점수 자체가 증거는 아니라는 점이 보도에서도 지적됨. 특정 개인을 부정행위자로 보이게 만들 수 있어 화면·게임 모두에서 제외한다.
